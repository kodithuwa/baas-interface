# Responsive and Accessibility Review

1. Read the screen specification and applicable `AGENTS.md`.
2. Inspect the implemented screen and existing project conventions.
3. Test or inspect available breakpoints: mobile, tablet and desktop. Use project-defined breakpoints where present.
4. Check for horizontal overflow, clipped content, unreadable text, awkward wrapping, and unusable navigation or controls.
5. Check semantic landmarks, heading order, form labels, button/link semantics, accessible names, keyboard operation, focus visibility and meaningful alt text.
6. Check colour contrast where measurable; do not guess compliance.
7. Check that hover is not the only way to discover or operate a control.
8. Preserve the desktop reference appearance while improving smaller breakpoints.
9. Fix issues within the current screen scope. Do not redesign unrelated screens.
10. Run relevant checks and report findings, changes, viewport sizes and remaining limitations.
